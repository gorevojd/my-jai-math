# my-jai-math

Scalar math, vectors, matrices, colors, transforms, geometry and interpolation for Jai.

## Dependencies

No other `my-jai-*` modules are required.

Jai standard library: `Basic`, `Math`, `Random`.

The standard `Math` module supplies selected scalar operations. This module defines
its own vectors, matrices, colors and constants.

## Import

```jai
Math :: #import "my-jai-math";
```

Add the directory containing `my-jai-math` to the compiler's module search path.
